# TO DO LIST APPLICATION


## overview 
 The TO DO LIST APPLICATION is simple to use app written in BASH that allows users to track their activities with options to add and delete task
 Add a new task to the list
 Display all tasks with line numbers
 Delete tasks by selecting their number
 Stores tasks in a local `tasks.txt` file

# add tasks
./todo.sh add "Buy groceries"


# List all tasks
 ./todo.sh list


 # delete tasks by number
  ./todo.sh delete 2
